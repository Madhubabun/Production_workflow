# Stretcher Lifecycle Explorer

An interactive learning website that shows how a medical device (a hospital patient transport stretcher) moves through its full lifecycle:

**Idea → 3D CAD (Creo) → Windchill (EBOM) → Review & Release → MBOM (MPMLink) → SAP → Production → Packaging & UDI → Service → Feedback (Complaint → CAPA)**

It covers PLM, QMS and regulatory concepts (FDA QMSR, ISO 13485, ISO 14971, EU MDR, UDI, and more), with hover tooltips, detailed explanations, 3D views and guided tours, so both technical and non-technical users can follow it.
